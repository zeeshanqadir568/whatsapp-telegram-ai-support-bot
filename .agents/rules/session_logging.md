# Session & Milestone Logging Rule

## Mandatory Workflow
At the end of every task, major achievement, or before concluding a session:
1. **Update `SESSION_LOG.md`**: Record all completed tasks, architectural changes, new endpoints, bug fixes, database schema modifications, and next steps in `SESSION_LOG.md` located in the repository root.
2. **Git Commit & Push**: Commit `SESSION_LOG.md` and project code to Git so progress is persisted remotely on GitHub.
3. **Continuation Context**: Include exact instructions, live endpoints, and pending roadmap items in the log so any future agent or developer can seamlessly resume work from the exact same state without loss of context.
